ようこそ LZ Editor へ！
このファイルは、スクリーンショット撮影・動作確認用のサンプルです。

■ VZ 互換キーバインド (エディタ画面)
  Ctrl+E / S / D / X : ダイヤモンドカーソル移動 (上/左/右/下)
  Ctrl+A / Ctrl+F    : 単語単位の左・右移動 (日本語・英数対応)
  Ctrl+Q+S / Q+D     : 行頭・行末移動 (Home / End)
  Ctrl+Y             : 現在行の削除
  Ctrl+G / BackSpace : カーソル位置 / 前1文字の削除
  Ctrl+W             : 複数バッファ（裏画面）切替
  Ctrl+K+D / F10     : 上書き保存 / 保存ダイアログ
  ESC / Ctrl+K+Q     : 2画面ファイラーへ瞬間切替

■ サンプルコード (Rust)
fn main() {
    let message = "ターミナルの制約を超えた、瞬間起動の VZ 体験。";
    println!("{}", message);
}
